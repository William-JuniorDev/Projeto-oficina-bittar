🛠️ Landing Page - Mecânica Bittar

Landing page institucional e responsiva desenvolvida sob medida para a oficina automotiva Mecânica Bittar, com foco em presença digital, otimização mobile e conversão de clientes via WhatsApp.

---

🚀 Tecnologias Utilizadas

- HTML5: Estrutura semântica e acessível.
- CSS3: Design responsivo (media queries), temas e layout moderno em Flexbox/Grid.
- JavaScript (ES6+): Interatividade do menu e navegação dinâmica.

---

✨ Funcionalidades e Destaques

- 📱 Design 100% Responsivo: Otimizado para navegação fluida em dispositivos móveis e desktops.
- 💬 Foco em Conversão: Botões de ação direta para agendamento e orçamentos via WhatsApp.
- 🎨 UI/UX Moderna: Interface em tema escuro profissional com alto contraste e boa leitura.
- 🖼️ Galeria Interativa: Exibição de serviços e integração visual com o perfil da oficina.

---
🔧 Como Executar o Projeto

Como o projeto foi desenvolvido em arquitetura estática pura, não é necessária a instalação de dependências ou servidores de backend.
